# Labs

Hands-on, code-along lab handouts, one per major topic, meant to be worked through in a lab session or on your own shortly after the matching lecture. Labs are shorter and more guided than the [`assignments/`](../assignments/) — they're for building intuition and comfort with the tools (NumPy, PyTorch, Hugging Face) before you're asked to apply them independently in an assignment.

All labs use Python 3.9+ and PyTorch unless noted otherwise. See the main [README](../README.md#technical-requirements) for environment setup.
